# VirtuLab Companion Portal

Gamified assessment and analytics portal for the VirtuLab offline chemistry lab.
Students finish a salt experiment, receive a completion code, redeem it here,
and take a quiz. Teachers see class-wide analytics and learning gaps.

**Phase W0a — Scaffold + Question Bank Converter**

## 1 — First-time setup (do this once)

### 1a. Copy the environment file and fill it in

```powershell
# Creates .env from the example; .env is in .gitignore and must never be committed
Copy-Item .env.example .env
```

Open `.env` in a text editor and replace every `change-me` value.
The minimum required value is `SECRET_KEY` — Django will refuse to start without it.

### 1b. Generate a safe SECRET_KEY

```powershell
# Prints a cryptographically random key you can paste into .env
backend\.venv\Scripts\python.exe -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

### 1c. Create the Python virtual environment (first time only)

```powershell
# Creates backend/.venv/ — this is in .gitignore
python -m venv backend\.venv
```

### 1d. Install Python packages

```powershell
# Installs Django 6.1.2, DRF 3.18.3, and python-dotenv into the venv
backend\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

### 1e. Install Node packages for the frontend

```powershell
# Installs React, Vite, Bootstrap, react-i18next, and i18next into frontend/node_modules/
npm install --prefix frontend
```

## 2 — Run the backend

```powershell
# Apply database migrations (creates db.sqlite3 in backend/)
backend\.venv\Scripts\python.exe backend\manage.py migrate

# Start the Django development server on port 8000
backend\.venv\Scripts\python.exe backend\manage.py runserver
```

Check it works: open http://127.0.0.1:8000/api/health/ in your browser.
You should see `{"status": "ok"}`.

---

## 3 — Run the frontend

Open a **second** PowerShell window and run:

```powershell
# Start the Vite dev server on port 5173
npm run dev --prefix frontend
```

Open http://localhost:5173 — you should see the "VirtuLab" heading.

## 4 — Import the question bank

```powershell
# Reads virtulab_data/source/Salt_Analysis_Question_Bank.txt
# Writes virtulab_data/question_bank.json and virtulab_data/import_report.txt
# Exits non-zero if any validation check fails
python tools\import_bank.py
```

To use custom paths:

```powershell
python tools\import_bank.py --src PATH\TO\bank.txt --out PATH\TO\out.json --report PATH\TO\report.txt
```

## Student app

### Running backend & frontend

1. **Start backend API** (terminal 1):
   ```powershell
   backend\.venv\Scripts\python.exe backend\manage.py migrate
   backend\.venv\Scripts\python.exe backend\manage.py runserver
   ```
   Backend listens at `http://127.0.0.1:8000/api`.

2. **Start frontend dev server** (terminal 2):
   ```powershell
   npm run dev --prefix frontend
   ```
   Open `http://localhost:5173` in a mobile-sized window (or 360 px devtools viewport).

### Testing with generate_demo.py

Generate demo completion codes and result tokens for any student ID and salt:

```powershell
# Generate completion code + token for CuSO4 with test secret
python lab_pack\generate_demo.py --student STU12345 --item cuso4 --use-test-secret

# Generate code + token with lab mistakes recorded
python lab_pack\generate_demo.py --student STU12345 --item nacl --att 2 --mis reagent_excess,skipped_flame --wrong CU:SO4 --use-test-secret
```

1. Log in or register with Student ID (e.g. `STU12345`) and 4-6 digit PIN.
2. Tap **Redeem a Code** (`/redeem`), paste the generated `CODE` and optional `TOKEN`.
3. Tap **Start Quiz** (`/quiz/<id>`) to take the adaptive quiz with autosave & review.
4. View score, points breakdown, badges, and lab insights on the **Results** screen (`/result/<id>`).
5. Use the bottom navigation to explore **Home**, **Badges** (`/badges`), **History** (`/history`), and **Settings** (`/settings`).

## Making every phase re-runnable

Each phase can be re-run from scratch by:
1. Deleting `backend/db.sqlite3` and re-running migrate.
2. Re-running `python tools\import_bank.py` to regenerate `question_bank.json`.
3. Re-running `npm install --prefix frontend` if `node_modules` was deleted.

See `docs/PHASE_W0A_REPORT.md` for the phase completion summary.
